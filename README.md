# PRODIGY_CS_05 - Network Packet Analyzer

## Objective

Develop a basic network packet analyzer that captures and analyzes
network packets for educational cybersecurity purposes.

## Features

- Captures network packets
- Displays source IP
- Displays destination IP
- Identifies common protocols
- Displays a limited payload preview
- Runs locally without storing captured packets

## Technologies

- Python
- Scapy

## Installation

```bash
pip install scapy
